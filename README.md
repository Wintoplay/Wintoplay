  Investigated prevalence bias (linguistic) and association bias (cultural); provided cultural parallel dataset; explored tugging effect between language script bias and cultural instruction.

- **Neural Dynamic Time Warping Ensemble** – Senior Capstone Project (Aug 2023 – May 2024)
